# AlarmMini v2.1.6

## Українська

- Автоматичне отримання даних від Tryvoha.online, коли MQTT і власний резервний API недоступні.
- Єдині з MQTT коди 0–5: відбій, червона або оранжева вся область, змішана тривога та часткова тривога.
- Вкладка «Джерела даних» у панелі плати: активне MQTT або Tryvoha підсвічується зеленим. Поля резервного URL і токена прибрано з цієї панелі.
- Історія оновлень на сайті. Під час оновлення зберігаються власні кольори, яскравість, нічний режим, часовий пояс та прив’язка LED.

Оновіть **прошивку та LittleFS** через режим зі збереженням налаштувань. Часові пояси й UA/EN з v2.1.5 збережені.

## English

- Automatic data from Tryvoha.online when MQTT and the custom fallback API are unavailable.
- MQTT-compatible codes 0–5: clear, whole-oblast red or orange, mixed alerts and partial alerts.
- The device dashboard now has a Data sources tab. Active MQTT or Tryvoha is highlighted green; fallback URL and token fields were removed from this dashboard.
- Release history on the website. Updating preserves custom colors, brightness, night mode, time zone and LED mapping.

Update **firmware and LittleFS** with settings preservation enabled. Time zones and UA/EN from v2.1.5 are retained.

[Tryvoha.online](https://tryvoha.online) · ESP32-C3 SuperMini · ESP8266 / Wemos D1 mini
