# AlarmMini v2.1.7

## Українська

- Три джерела даних у порядку MQTT → Tryvoha → власний URL, з автоматичним поверненням після відновлення.
- У панелі плати повернуто резервний URL; активне джерело з трьох підсвічується зеленим.
- Одне поле URL у панелі плати та інсталяторі. Токен передається в GET-параметрі адреси.
- Для нових плат задано типовий URL /public/status. Оновлення зберігає власні адреси, кольори, нічний режим та решту конфігурації.

Оновіть **прошивку та LittleFS** у режимі зі збереженням налаштувань. Власний URL очікує JSON-масив із 25 кодів 0–255 у порядку MQTT.

## English

- Three data sources in priority order: MQTT → Tryvoha → custom URL, with automatic return when a source recovers.
- Restored the fallback URL field in the device dashboard; the active source is highlighted green.
- A single URL field in the dashboard and installer. Include the token as a GET query parameter.
- New devices use the default /public/status URL. Updates preserve custom URLs, colors, night mode and other settings.

Update **firmware and LittleFS** with settings preservation enabled. The custom URL must return a JSON array of 25 codes from 0 to 255 in MQTT order.
