# AlarmMini v2.1.5

## Українська

- Часовий пояс на сайті й у панелі пристрою: пошук країни/міста, визначення з браузера, автоматичний літній/зимовий час. Каталог IANA 2026d містить 598 назв і сумісних псевдонімів, включно з дробовими зміщеннями.
- Часовий пояс зберігається в JSON (`tz`), застосовується без перезапуску й керує нічним режимом та часом у журналах. Старі конфігурації зберігають Europe/Kyiv.
- UA / EN розташовано поруч із назвою AlarmMini. Перевірено компонування від 320 до 1920 px.
- Виправлено відображення й збереження резервного URL та токена у вебпанелі: значення читаються з конфігурації, а зміни інших параметрів їх не стирають.
- Початковий JSON-профіль із шістьма станами, сервісним паролем MQTT і токеном резервного API входить до нової інсталяції. Сервісні дані розповсюджуються за дозволом власника; Wi-Fi налаштовується окремо.
- Посібник UA + EN на одному аркуші A4 (дві половини A5), двомовний README і ліцензія для некомерційного використання. PDF та JSON доступні на сайті й серед файлів релізу.

Оновлюйте **прошивку та LittleFS** через режим зі збереженням налаштувань. Після завершення оновіть сторінку плати. Сумісні плати: ESP32-C3 SuperMini та ESP8266 / Wemos D1 mini.

## English

- Time-zone controls on the website and device dashboard: country/city search, browser detection and automatic daylight saving. IANA 2026d supplies 598 identifiers and aliases, including fractional offsets.
- The `tz` JSON setting applies without restarting and controls night mode and log timestamps. Legacy configurations retain Europe/Kyiv.
- UA / EN now sits beside the AlarmMini brand. Responsive layouts checked from 320 to 1920 px.
- Fixed fallback URL/token loading and persistence in the device dashboard; unrelated settings no longer clear these values.
- New installations include the six-state JSON profile with owner-authorized MQTT service credentials and fallback API token. Home Wi-Fi is configured separately.
- Bilingual one-sheet A4 guide (two A5 panels), bilingual README and non-commercial licence. PDF and JSON downloads are available on the website and in this release.

Update **both firmware and LittleFS** with settings preservation enabled, then refresh the device page. Supported: ESP32-C3 SuperMini and ESP8266 / Wemos D1 mini.
