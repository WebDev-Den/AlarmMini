# Часовий пояс (версія 2.1.5)

На сайті під час першого встановлення обери країну/місто через пошук або натисни «Визначити з браузера». Для подарунка вибирай місце одержувача. На вже налаштованій платі пояс можна змінити через сайт по USB або в панелі пристрою: «Нічний режим» → «Часовий пояс» → «Зберегти».

Нічний режим і час у журналах використовують обраний пояс. Перехід на літній/зимовий час автоматичний, зокрема зі зміщеннями на 30 і 45 хвилин. Без нового поля в старій конфігурації зберігається попередній Europe/Kyiv. Нове поле JSON: `"tz": "America/Los_Angeles"`. Зміна застосовується без перезапуску.

Дані: IANA tzdb 2026d, 598 ідентифікаторів та сумісних псевдонімів. `firmware/work_data/timezones.json` — джерело правил; `firmware/scripts/prepare_timezones.py` генерує flash-таблицю та браузерний список. Правила й відомі майбутні нерегулярні переходи зберігаються у PROGMEM, список пошуку обробляє браузер. Жодного запиту до зовнішнього сервісу для визначення правил не потрібно. Системний час синхронізується через наявний NTP.

Правила відображають законодавство на дату бази IANA. Для майбутніх змін правил у країнах потрібно оновити базу разом із прошивкою. Джерела: https://data.iana.org/time-zones/tzdb/ та Python-пакет tzdata 2026.4 (IANA 2026d). Перед оновленням перевір фактичну версію пакета через tzdata.IANA_VERSION.

Перевірки: збірка firmware і LittleFS для ESP32-C3 та ESP8266, перевірки збереження/відновлення конфігурації, пошуку, вибору, UA/EN та мобільного компонування.
