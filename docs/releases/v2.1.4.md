# AlarmMini v2.1.4

- Українська та англійська мови на сайті, у панелі плати та під час першого налаштування Wi-Fi. Перемикач UA / EN запам’ятовує вибір у браузері.
- Виправлено мобільне компонування панелі, меню дій, QR-кодів і калібрування.
- Нові плати отримують початковий профіль користувача від 22.09.2026: шість станів, задані кольори та яскравість, нічний режим 22:00–07:00, прив’язку 27 LED, MQTT і резервний API з паролем та токеном.
- Прошивка читає початковий `/config.json` лише за відсутності збереженої конфігурації. Оновлення через інсталятор зберігає наявні налаштування.

Профіль з обліковими даними призначений власником для розповсюдження новим користувачам і входить у загальнодоступні файли інсталятора та прошивки. Домашній Wi-Fi кожен користувач налаштовує самостійно.

## Оновлення

В інсталяторі виберіть v2.1.4 та «Оновлення зі збереженням налаштувань». Потрібно записати і прошивку, і файлову систему: сам коміт у Git або оновлення лише firmware.bin не замінює вебпанель на платі. Після оновлення перезавантажте сторінку плати.
