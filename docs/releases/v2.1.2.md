# AlarmMini v2.1.2

У панелі плати додано текстове введення RGBA окремо для денного й нічного
кольору кожного стану. Наприклад, `rgba(255, 160, 0, 0.5)` задає оранжевий
із яскравістю близько 50%.

- RGB: цілі значення 0–255; A: яскравість 0–1.
- Поле RGBA синхронізоване з вибором кольору та повзунком яскравості.
- Некоректний RGBA блокує збереження; нічне обмеження залишається чинним.
- Формат конфігурації, MQTT/HTTP та резервні копії сумісні з 2.1.0–2.1.1.

Потрібно оновити **прошивку та LittleFS** зі збереженням налаштувань.
Підтримуються ESP32-C3 SuperMini та ESP8266 / Wemos D1 mini.
