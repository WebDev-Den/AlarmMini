# AlarmMini v2.0.6

Оновлення стабільності та використання пам’яті для ESP32-C3 SuperMini й ESP8266 / Wemos D1 mini.

- Портал налаштування продовжує працювати без роутера, а плата повторює підключення після його появи. Відновлюються AP і DNS після помилок запуску.
- Усунено конфлікти повторного підключення Wi-Fi, блокувальне налаштування та ризик прийняти старе з’єднання за перевірку нового пароля.
- Посилено збереження й відновлення конфігурації при перериванні живлення: перевірка CRC і фактично записаних даних, відновлення тимчасової копії, збереження придатної резервної копії, без автоматичного форматування LittleFS.
- Обмежено блокування MQTT/DNS/TCP, перевіряються повні MQTT-повідомлення, зменшено зайві записи flash. Покращено обробку UART і діагностику перезапусків.
- Виправлено роботу звуку на ESP32-C3, завершення останньої ноти та дотримання обмежень яскравості.
- Зменшено статичне використання RAM приблизно на 4 КіБ для ESP32-C3 та 3,5 КіБ для ESP8266 порівняно зі збіркою після аудиту. Буферизовано HTTP JSON, зменшено піки RAM при міграції конфігурації та пропущено незмінені LED-кадри з періодичним оновленням.

Формат конфігурації й USB-протоколи сумісні. Для наявної карти використовуйте режим оновлення зі збереженням налаштувань; перше встановлення стирає наявну конфігурацію.

Усі 7 `.bin` файлів потрібні вебінсталятору; `SHA256SUMS.txt` містить їхні контрольні суми. LittleFS-образи зібрані з публічного шаблону без особистих Wi-Fi-параметрів.

Перевірки: збірки обох платформ, тести Wi-Fi/AP/DNS, 877 модельованих переривань запису конфігурації, 72 переривання запису MQTT-знімка, UART/CRC/JSON, міграція, LED і звук. На підключеному ESP32-C3 попередньо перевірено прошивання, відновлення конфігурації та відповідність USB-передавання; ESP8266 перевірявся збіркою й host-тестами. Радіоефір, просадки напруги й тривала робота потребують окремих апаратних випробувань.

Вебінсталятор: https://alarmmini.vercel.app/
