# Мови інтерфейсу та мобільна версія

Сайт інсталятора, панель пристрою та початкове Wi-Fi налаштування підтримують **UA / EN**. Українська — типова мова. Вибір зберігається в браузері (`alarmmini.locale`) окремо для адреси сайту та кожного пристрою. Якщо сховище браузера недоступне, перемикання працює до перезавантаження сторінки.

## Редагування перекладу

- [ua.json](../firmware/work_data/locales/ua.json) — українські тексти.
- [en.json](../firmware/work_data/locales/en.json) — англійські тексти.

Це спільні словники для сайту та пристрою. Ключі — вихідні українські фрази; вони служать сталими ідентифікаторами. Змінюй **значення праворуч**, залишаючи ключі незмінними. Для нової фрази додай однаковий ключ у два файли. Позначки `{0}`, `{1}` тощо підставляють номер стану, відсоток, адресу або текст помилки: збережи їх у перекладі.

Приклад:

```json
{
  "Зберегти": "Save",
  "Записуємо прошивку: {0}%. Не відключай USB.": "Writing firmware: {0}%. Keep USB connected."
}
```

Позначення мови в інтерфейсі та назва файлу — `ua`; HTML використовує стандартний код української `uk`. Непідтримуваний вибір мови повертає український інтерфейс.

Переклад змінює відображення, а не дані: SSID, паролі, токени, JSON конфігурації, MQTT-топіки та ідентифікатори областей залишаються незмінними. Перемикання не перезавантажує сторінку й не скидає незбережені поля чи підтвердження встановлення.

## Збірка

Next.js імпортує словники зі спільної папки. Збирай сайт із повного checkout репозиторію; кореневий `vercel.json` уже задає цей режим. Після зміни словників сайт потрібно перебудувати.

Панель пристрою завантажує JSON із LittleFS, без зовнішнього сервісу перекладу. Після змін потрібно зібрати та оновити образ LittleFS.

Початковий Wi-Fi портал має працювати навіть із відсутньою файловою системою. Тому `prepare_i18n.py` під час збірки вбудовує вибрані фрази зі словників у прошивку. [provision-keys.json](../firmware/work_data/locales/provision-keys.json) визначає ці фрази; після зміни перекладу порталу перебудуй також прошивку. Згенерований заголовок залишається в `.pio/build/<плата>/generated/`, його не потрібно редагувати чи комітити. Відповідь порталу передається частинами, щоб не збирати весь переклад у RAM пристрою.

## Виправлення мобільного дизайну

Перевірку проведено з урахуванням [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md).

- Перемикач мови доступний у шапці сайту, панелі та на екрані входу.
- На телефоні службові дії пристрою згорнуто; кнопка збереження незбережених змін залишається окремо.
- Навігація панелі переноситься в сітку, назви вкладок не обрізаються.
- Виправлено висоту мапи, масштаб калібрування та вихід QR-карток за край.
- Поля на телефоні мають шрифт 16 px; основні кнопки та кольорові елементи — область натискання щонайменше 44 px.
- Додано видимий фокус, керування вкладками Wi-Fi/MQTT стрілками, підтримку зменшеної анімації та відступи безпечної зони екрана.

## Перевірки

Автоматизовані браузерні сценарії перевіряють обидві мови, екрани 320/390/768/1280 px для сайту, панель на вузькому екрані, редактор конфігурації, збереження введених даних, англійський пошук областей, переклад відповідей сервера та Wi-Fi портал без файлової системи й інтернету.

```powershell
npm --prefix vercel test
npm --prefix vercel run typecheck
npm --prefix vercel run build
# Запусти сайт окремо, потім:
npm --prefix vercel run test:browser
node firmware/tests/state_colors_ui_test.js
node firmware/tests/provision_ui_test.js
platformio run --project-dir firmware -e esp32c3 -e esp8266
platformio run --project-dir firmware -e esp32c3 -e esp8266 -t buildfs
```

Перевірка в браузері використовує змодельовані відповіді плати. Фізичне USB-прошивання та перевірка на реальному телефоні/пристрої до неї не входять.
