# Сумісність v2.1.3 з Wemos D1 mini

Перевірено 8 вересня 2026 року. Поточна прошивка збирається для **Wemos / LOLIN
D1 mini на ESP8266EX із 4 МБ Flash**. У вебінсталяторі потрібно вибрати
**ESP8266 / Wemos D1 mini**.

За [документацією виробника](https://www.wemos.cc/en/latest/d1/d1_mini_3.1.0.html)
ця плата має 4 МБ Flash, а контакт **D1 відповідає GPIO5**. У поточній прошивці
`LED_PIN = 5`, тому сигнал DIN світлодіодів підключається до **D1**.

## Перевірені параметри

| Параметр | Результат |
| --- | --- |
| PlatformIO | `esp8266`, плата `d1_mini`, платформа `espressif8266@4.2.1` |
| Arduino ESP8266 core | 3.1.2 |
| Процесор / Flash | 80 МГц / 40 МГц, режим DIO, 4 МБ |
| Статично зайнята RAM | 55 712 із 81 920 байтів — 68% |
| Код у Flash за звітом збірки | 590 459 із 1 044 464 байтів — 56,5% |
| Релізний файл прошивки | 594 608 байтів, запис із `0x000000` |
| LittleFS | 2 072 576 байтів, запис із `0x200000` |
| Кінець LittleFS | `0x3FA000`; образ не заходить у службову область Flash |
| LED | до 27, дані через D1 / GPIO5 |

Адреса LittleFS у вебінсталяторі звірена із символами `_FS_start` / `_FS_end`
реального ELF-файлу та розміром релізного образу. Заголовок завантажувального
образу підтверджує ESP8266, DIO, 40 МГц і 4 МБ. Контрольні суми завантажених
релізних файлів збігаються з `SHA256SUMS.txt`.

Збірки прошивки й LittleFS успішні. Пройшли тести серіалізації та перенесення
конфігурацій на 32-бітній тестовій платформі для ESP8266 й ESP32, а також
перевірки реальних функцій MQTT/HTTPS, кодів 0–255, пульсації при зміні,
нічної яскравості й відновлення знімків після збоїв запису.

## Межі перевірки

Це перевірка коду, збірки та релізних файлів. **Фізичну Wemos D1 mini не
прошивали й не перевіряли під навантаженням:** під час перевірки підключена лише
ESP32-C3. Звіт статичної RAM не означає вимірювання вільної пам’яті під час
роботи Wi-Fi або TLS. У збірці ESP8266 розширений портал сканування Wi-Fi
вимкнений для економії пам’яті; налаштування SSID/пароля через USB збережене.

Для цієї плати використовуються тільки `alarmmini-esp8266-firmware.bin` та
`alarmmini-esp8266-littlefs.bin` з актуального релізу. Інсталятор сам вибирає їх
і правильні адреси запису, а в режимі оновлення зберігає конфігурацію.
