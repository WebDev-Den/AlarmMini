# Палітра шести AIR-станів UkraineAlarm

Файл `ukrainealarm-air-6-states.json` можна завантажити через **Імпорт налаштувань**
у локальній вебпанелі плати з прошивкою 2.1.0 або новішою. Він змінює лише
кольори `c` і додаткову палітру `sc`; поточні Wi-Fi, MQTT, HTTP-токен,
калібрування та розклад нічного режиму беруться з плати під час імпорту.
Палітра додаткових станів замінюється цілком на коди 2–5.

| Код | Значення на сервері | Денний RGB | Яскравість день / ніч |
| --- | --- | --- | --- |
| 0 | Відбій | 0, 255, 0 — зелений | 255 / 0 |
| 1 | Червоний на всю область | 255, 0, 0 — червоний | 255 / 25 |
| 2 | Оранжевий на всю область | 255, 160, 0 — оранжевий | 255 / 25 |
| 3 | Будь-яке поєднання червоного й оранжевого | 255, 100, 0 — червоно-оранжевий | 255 / 25 |
| 4 | Частково червона область | 255, 80, 80 — світло-червоний | 160 / 16 |
| 5 | Частково оранжева область | 255, 210, 0 — золотистий | 160 / 16 |

Яскравість задана байтами 0–255: 25 ≈ 9,8%, 160 ≈ 62,7%, 16 ≈ 6,3%.
Для активних станів нічний RGB збігається з денним; затемнення задається
четвертим каналом. Додатково діють нічне обмеження та ефекти прошивки.
Огляд мапи показує денний RGB без яскравості; LED застосовують обидва параметри.

Для коду без власного кольору прошивка використовує червоний колір стану 1.
Саме тому відсутній код 5 у старому конфігу виглядає як червона тривога.

Код 3 тут має один змішаний відтінок. JSON-палітра не задає чергування двох
кольорів або смуги. Так само коди 4/5 фарбують усю область умовним кольором
часткової тривоги: масив із 25 кодів не містить геометрії районів і громад.

Значення кодів відповідають AlarmMini Server з шістьма станами AIR. Для MQTT
потрібен топік `ukraine/alarm/map/full_v2`; старий `full` містить лише 0/1.
