# Панель AlarmMini

Панель оператора локального сервера: спочатку стан карти й свіжість даних,
далі діагностика доставки та налаштування. Без зовнішніх шрифтів і бібліотек UI.

Палітра: чорнило `#172c36`, туман `#eff3f1`, папір `#ffffff`,
бірюза `#126b67`, тривога `#da5c52`, попередження `#e0a33b`.
Темна тема використовує синьо-зелені поверхні та ті самі значення станів.
Segoe UI Variable / Segoe UI — український інтерфейс; Cascadia Mono / monospace —
лише числові показники, адреси та коди. Шкала 12 / 14 / 16 / 20 / 28 / 36 px.

Композиція: вузька навігація зліва; велика карта з рівними за значенням областями;
праворуч розподіл станів, унизу компактний ряд ресурсів. Текст вирівняно вліво.

```text
┌──────────────┬────────────────────────────────────────────────┐
│ AlarmMini    │ Огляд                          свіжість / час  │
│ Огляд        ├─────────────────────────────┬──────────────────┤
│ Тривоги      │                             │ Розподіл станів  │
│ Ресурси      │        Карта України        │ Коди 0–5         │
│ Підключення  │                             │ Доставка даних   │
│ DuckDNS      ├─────────────────────────────┴──────────────────┤
│ Журнал       │ CPU процесу / RAM / час роботи / запити       │
│ Тема / вихід │ Графік ресурсу або журнал у своєму розділі     │
└──────────────┴────────────────────────────────────────────────┘
```

Перевірка плану: замість набору однакових карток — карта як основна робоча
поверхня, лінійки чисел і таблиці. Прибрано декоративні номери й великі літери.
Змішані та часткові стани мають власне штрихування; воно не позначає географію
районів. Немає даних — нейтральна карта, застарілі — чітке попередження.
Лічильники й історія обмежені пам’яттю; статистика не бере участі у доставці
тривог. Клавіатура, вузький екран і обидві теми перевіряються окремо.
