Публічний доступ

HTTPS-домен із Cloudflare Tunnel, без /public у кінці.

Масив із 25 станів. Для прошивки можна передавати токен у заголовку Authorization: Bearer ….

Посилання містить окремий токен. Додатково перевіряється підпис UkraineAlarm.

Webhook UkraineAlarm

Спочатку перевір адресу. Перед реєстрацією та оновленням сервер повторно перевірить доставку POST і наявність ключа підпису.

Перевірка публічної адреси

Перевірку ще не виконано.

Тест перевіряє HTTPS, маршрут і токен. Він не змінює карту чи підписку і не є подією UkraineAlarm.

Перевірка підпису

—

Якщо Cloudflare блокує автоматичне завантаження, відкрий офіційний публічний ключ у браузері та збережи файл. Завантаж сюди саме цей файл; власний ключ не підходить.

Реальні webhook завжди потребують правильного підпису. Планове опитування API працює і без webhook.

Cloudflare Tunnel

Відкрий назовні лише шлях ^/public/.*$. Локальна панель і її налаштування доступні через адресу сервера у твоїй мережі.

Постійна адреса сервера

Сервер перевіряє IPv4 і оновлює DuckDNS, коли адреса змінилася.

Введи коротке ім’я або повну адресу без http:// і порту. Домен має вже існувати у твоєму акаунті DuckDNS.

Токен ще не збережено.

Порожнє поле — зовнішній IPv4 цього сервера через ipify. Якщо MQTT-брокер в іншій мережі, вкажи його публічний IPv4 вручну. Змінюється лише IPv4-запис.

Після ввімкнення й збереження сервер одразу перевірить адресу, а далі — за розкладом. Якщо IPv4 збігається, запит оновлення не надсилається.

Спочатку збережи зміни, щоб перевірити саме ці налаштування.

«Перевірити» лише порівнює адреси й не перевіряє токен. «Оновити зараз» надсилає запит у DuckDNS навіть при збігу IP та перевіряє доступ. DNS-кеші можуть оновитися із затримкою.

Один механізм оновлення

Вимкни попередній updater DuckDNS на роутері чи іншому сервері, якщо він може записувати інший IP. Це оновлення адреси, а не автоматичне перемикання на резервний сервер.
